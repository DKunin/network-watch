# Changelog

## 2026-09-17

- Сервис переведен на `https://network.kunini.ru` с единой сессией `auth.kunini.ru`.
- Backend ограничен loopback-интерфейсом и принимает только проверенную Nginx identity; API опубликован под `/api`.
- Добавлены Nginx/Certbot-конфигурация, защищенный выход из веб-интерфейса и проверки auth-контракта.

## 2026-09-14

- К выбору даты добавлены кнопки перехода на предыдущий и следующий день.

## 2026-09-08

- Добавлена карточка почасовой активности устройства с общим временем онлайн, пиковым часом и тепловой картой за сутки.
- Интерфейс переработан в компактный одноэкранный дашборд без дублирующих блоков; управление Telegram-уведомлениями убрано из UI.
- Dev-сервер больше не перезапускается при обновлении файлов с данными мониторинга.
- Для ячеек почасовой активности добавлены подсказки с точным количеством минут онлайн, доступные при наведении и фокусе с клавиатуры.
- Исправлена гонка при быстром переключении устройств, из-за которой семидневный график мог перестать отображаться с ошибкой Chart.js.

## 2026-06-29

- Обновлен список отслеживаемых устройств: `TV` переименован в `Den TV`, добавлен `Kir's TV`.
- Уточнено, что клиенты получают список устройств через `GET /devices`.
